# StudioCam

אפליקציית צילום והקלטה מקצועית - שלב 1.

## מה יש בשלב הזה
- תצוגת מצלמה חיה + הקלטת וידאו (CameraX)
- זיהוי כרטיס הקול החיצוני (USB Audio Class) וכל הכניסות שלו
- שני ערוצי אודיו: שם ניתן לעריכה, בחירת כניסת אודיו, ווליום, פאן, LED meter חי (מדידה אמיתית מהאות הנכנס)
- פאנל אפקטים (Reverb + Delay) - הממשק מלא כולל מתגי ON/OFF ובקרות Mix/Size/Feedback, אבל העיבוד בפועל (DSP) עדיין לא מחובר לאודיו - זה נכנס בשלב הבא עם מנוע Oboe בעל latency נמוך
- עיצוב סינמטי מינימליסטי (שחור, כפתור הקלטה אדום, מגירת מיקסר תחתונה)

## מה עוד לא מוכן
- ה-DSP של Reverb/Delay בפועל
- אפקטים ויזואליים בזמן אמת על הווידאו
- מיזוג ערוצי האודיו המעובדים לתוך קובץ הווידאו המוקלט (כרגע ההקלטה מבוססת על צינור הווידאו של CameraX בלבד)

## איך לבנות APK
1. יוצרים ריפו חדש ב-GitHub ומעלים את כל התוכן של התיקייה הזו (כולל `.github`)
2. ה-workflow `.github/workflows/build-apk.yml` ירוץ אוטומטית על push ל-main
3. ה-APK יופיע גם כ-Artifact וגם תחת Releases של הריפו, בשם `studiocam.apk`
4. מורידים ומתקינים על הטלפון (יש לאפשר התקנה ממקורות לא ידועים)
